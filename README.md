# سوق أرباب المعاصر — V3 Preview

نسخة تجريبية موحدة التصميم لمنصة مهنية شبيهة في تجربة الاستخدام بمنصات الإعلانات المبوبة، متخصصة في زيت الزيتون ومعدات المعاصر.

## الصفحات
- index.html — الرئيسية
- search.html — نتائج البحث والتصفح
- listing.html — صفحة الإعلان التفصيلية
- publish.html — نشر إعلان

## ملاحظة
هذه نسخة واجهة وتجربة استخدام تجريبية. البيانات الجديدة تحفظ محلياً في المتصفح فقط. المرحلة التالية للإطلاق الرسمي: ربط قاعدة بيانات مشتركة، تخزين الصور، حسابات المستخدمين، وإدارة الإعلانات.
